public_html/.htaccess   -   THE LINES TO ADD
============================================

The site lives in public_html/avantehospitality/ but is served from the domain
root, so the address bar never shows the folder name.

IMPORTANT - WHY EVERY LINE NAMES THE DOMAIN
-------------------------------------------
A .htaccess in public_html is also read by the OTHER domains in this account,
because they are served from folders inside public_html. That was verified on
Apache, not assumed. Every rule below is therefore limited to
avantehospitality.co.za. Without that condition, the other domains would be
rewritten into this site's folder and break.

IF public_html/.htaccess ALREADY EXISTS
---------------------------------------
Do NOT replace it. Paste the block below at the very END of the file. It has to
come last, because the final rule stops Apache processing any further rules - so
anything after it would never run.

IF IT DOES NOT EXIST
--------------------
Create public_html/.htaccess (in the File Manager: create a file, then rename it
to .htaccess, including the leading dot) and paste the block in as-is.

Worth knowing: if the existing file has rules of its own without a domain
condition, those rules are already being applied to the other domains too. You
do not have to change that today, but it explains odd behaviour if you ever see
it.


--------------------------- copy from here ---------------------------

# Avante Hospitality: serve the site from the /avantehospitality folder.
RewriteEngine On

# Only for this site's own domain - the other domains here share this file.
RewriteCond %{HTTP_HOST} ^(www\.)?avantehospitality\.co\.za$ [NC]
RewriteCond %{THE_REQUEST} \s/+avantehospitality(?:/|\s)
RewriteRule ^avantehospitality/?(.*)$ /$1 [R=301,L]

RewriteCond %{HTTP_HOST} ^(www\.)?avantehospitality\.co\.za$ [NC]
RewriteRule ^admin/?$ avantehospitality/admin/index.php [L]

RewriteCond %{HTTP_HOST} ^(www\.)?avantehospitality\.co\.za$ [NC]
RewriteRule ^(?!avantehospitality/)(.*)$ avantehospitality/$1 [L]

---------------------------- to here -----------------------------


CHECKING IT WORKED
------------------
- https://avantehospitality.co.za/                -> the site, address unchanged
- https://avantehospitality.co.za/api/health.php  -> {"ok":true,...}
- https://avantehospitality.co.za/admin/          -> the sign-in page
- any of the other domains                        -> still its own site

If you see a 500, the block was probably pasted above rules that stop processing;
move it to the end of the file. "Request exceeded the limit of 10 internal
redirects" in the error log means one of the domain conditions is missing.
